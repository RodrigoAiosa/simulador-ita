# ✈️ Simulado ITA — Aeronáutica

Plataforma de simulado do ITA com design inspirado na Força Aérea Brasileira.

## 🚀 Como executar

```bash
# Instalar dependências
pip install -r requirements.txt

# Rodar a aplicação
streamlit run app.py
```

## 📚 Funcionalidades

- **Simulado Personalizado**: Selecione anos (2021–2024), matérias e número de questões
- **3 Modos**: Cronometrado | Livre | Revisão Imediata
- **Navegação Rápida**: Salte entre questões livremente
- **Gabarito Completo**: Com resolução passo a passo
- **Estatísticas por Matéria**: Desempenho detalhado ao final
- **Histórico de Simulados**: Acompanhe sua evolução
- **Banco de Questões**: Explore todas as questões com filtros
